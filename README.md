# AI 비전 기반 조주기능사 실기 트레이닝 AR 솔루션 웹서비스

조주기능사 실기 시험 준비 과정을 혁신하기 위한 **AI 비전 센싱 및 AR 글래스 기반 트레이닝 솔루션**의 소개 웹사이트이자 가상 체험 웹 서비스입니다.

## 🔗 Live Demo (GitHub Pages)
- **접속 링크**: [https://slugmilk.github.io/AR-Bartender-Education-services/](https://slugmilk.github.io/AR-Bartender-Education-services/)

## 칵테일 가상 조주 시뮬레이터 (Interactive AR HUD Simulator)
웹 사이트 내에서 실제 솔루션의 AR HUD 가이드와 AI 피드백 시스템을 가상으로 직접 조작하고 결과 리포트를 받아볼 수 있는 데모를 제공합니다.
- **마티니(스터 기법)** 및 **위스키 사워(셰이킹 기법)** 레시피 실습 제공
- 지거/바 스푼/셰이커 스캔 및 도구 쥐기 인터랙션
- 병 기울이기 슬라이더 및 푸어링 홀드 동작을 통한 계량(oz) 추적
- 바 스푼 돌리기 및 셰이킹 액션 연타 모션
- 100점 만점 기준의 감점 요인 분석 및 AI 모션 총평 결과 리포트 출력

## 주요 기술 스택
- **Core**: HTML5, CSS3, Vanilla JavaScript
- **Icons**: Lucide Icons
- **Design Style**: Glassmorphic UI, Neon Accent & Dark Theme

## 개발 폴더 구조
- `/index.html`: 메인 웹 페이지 마크업
- `/styles.css`: 디자인 시스템 및 반응형 CSS 스타일시트
- `/app.js`: 시뮬레이터 비즈니스 로직 및 인터랙티브 UI 스크립트
